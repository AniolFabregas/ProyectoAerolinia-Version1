## Description
Application to manage airline information: load, show, add, remove and save aircrafts and flights, and plot the number of flights on air per hour.

## Files
- `aircraft.py`: Aircraft class and aircraft functions
- `flight.py`: Flight class and flight functions
- `airline.py`: Airline class and flights plot
- `interface.py`: tkinter graphical interface (run this file)
- `Aircrafts.txt`, `operations.txt`: data files
